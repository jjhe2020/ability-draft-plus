# 中文界面与 ggxgg 单技能选位

程序默认使用简体中文。设置中的语言选项也可以切换界面语言。识别结果、技能详情、组合推荐、英雄列表和直播页面使用内置的 Valve 中文名称；刷新 Windrun 数据不会覆盖中文显示。

## 使用方法

1. 在“数据”页面更新一次 Windrun 数据。旧数据库没有保存真实选取频率，需要更新才能计算新公式。
2. 打开“设置 → 单技能选位规则”。默认选择“ggxgg 自定义公式”。
3. 可以直接修改“胜率系数”和“选位系数”，默认分别为 `-1`、`10`，对应原表 S1、U1。也可以修改完整计算表达式。
4. 下方预览立即显示当前全量 Windrun 数据中的前五个技能。确认后点击“保存规则”。
5. 在悬浮窗重新识别或重新扫描，应用保存后的规则。技能提示框显示“公式选位”，数值越低越强。负数或大于 40 的结果有效，不会被截断。

公式和参数保存在本地数据库中，重启后继续使用。选择“原有综合评分”可以恢复原程序的排序方式，编辑过的公式仍然保留。

## 与 Excel 对应的计算

参考工作簿“最终排行”中的“ggxgg公式选位”，对应 C 列引用的 W 列：

```text
winZ  = (胜率 − 全量平均胜率) / 胜率样本标准差
pickZ = (平均选位 − 全量平均选位) / 平均选位样本标准差

调参值 = winWeight * (ABS(winZ)^2 * SIGN(winZ) + 2 * winZ)
         + pickWeight * pickZ * pickFrequency

公式选位 = (调参值 − 全量平均调参值)
           * 平均选位样本标准差 / 调参值样本标准差
           + 全量平均选位
```

界面中的表达式编辑器修改“调参值”（原表 V 列）。系统统一执行最后一步转换（原表 W 列），让结果继续以平均选位的尺度显示。标准差采用 Excel `STDEV` 的样本定义，分母为 `N−1`。全量基准包括当前所选补丁的全部技能和英雄模型，使用 Windrun 最新数据快照，包含未出现在当前截图中的样本。

`pickFrequency` 对应 Windrun 的 `pickRate`，表示真实选取频率，使用 0–1 小数。`avgPick` 对应 `avgPickPosition`。程序原有数据库字段 `pickRate` 实际保存平均选位，因此新增 `draftFrequency` 独立保存真实选取频率。胜率 `winrate` 也使用 0–1 小数。

## 可编辑变量

| 变量 | 含义 |
| --- | --- |
| `winWeight` | 胜率系数，默认 -1 |
| `pickWeight` | 选位系数，默认 10 |
| `winZ` | 胜率标准分 |
| `pickZ` | 平均选位标准分 |
| `pickFrequency` | 真实选取频率，0–1 |
| `winrate` | 原始胜率，0–1 |
| `avgPick` | 原始平均选位 |
| `winMean`、`winStd` | 全量平均胜率、样本标准差 |
| `pickMean`、`pickStd` | 全量平均选位、样本标准差 |

支持 `+ - * / ^`、括号和 `ABS`、`SIGN`、`SQRT`、`POWER`、`MIN`、`MAX`。公式只解析数学运算，不执行 JavaScript。无效表达式、除零、非有限结果会显示错误；保存失败时保留编辑内容以便修改后重试。

自定义模式让单技能严格按公式升序排列，不叠加原有的个人胜率混合、分路评分加减和精选技能保送。组合协同优先级、已有大招过滤、技能依赖和模型适配等筛选继续生效。英雄模型自身仍使用原来的模型评分。

缺失数据不会被当成零频率或中性胜率。无法计算的技能显示数据不足提示，暂不进入单技能推荐。某项标准差为零时，其标准分按零处理；全部调参值相同时，最终选位并列为平均选位。

## 本场分布与框内选位

完成扫描后，控制栏对侧默认展开“本场终极技能”和“本场英雄模型”两张独立表格。第一列为中文名称，第二列为 GGXGG 推算选位，按数值从低到高排列。每张表分别使用 Excel 风格的绿—黄—红条件格式：最低值为绿色，中位数为黄色，最高值为红色；全部并列时统一为黄色。点击表头可折叠，较小屏幕支持滚动。

两张表分别显示本场均值、方差和标准差。这里统计的是整场候选集合，方差分母为有效条目数 `N`；这与公式全量标准化使用的样本标准差 `N−1` 是两件事。无法计算的条目显示 `—`，不参与统计或染色。重扫后已选大招仍计入本场分布并标注“已选”，模型表同样保留已选模型。

所有已识别的池内技能和英雄模型还会在原框内常显两位小数的公式选位，无需悬停。数字文字使用相同的绿—黄—红条件色阶，保留深色底以便在图标上阅读。大招和模型的字色与对应表格的染色完全一致；普通技能按本场普通技能集合独立染色，已选技能仍计入色阶基准，重扫后剩余数字不会因移除已选项而整体变色。

数值直接使用已有的全量 GGXGG 公式结果，不在本场重新标准化；英雄模型的原有推荐评分保持原样。扫描截图期间表格和框内数值自动隐藏，避免干扰识别。使用“原有综合评分”模式时不计算公式选位，切回 GGXGG 并重新扫描即可显示。
