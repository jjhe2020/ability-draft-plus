# GGXGG 技能与英雄模型强度榜

中文 Dota 2 技能征召排行榜，默认将 513 个技能与 127 个英雄模型放在同一个总榜，按原参考表的 ggxgg 公式选位升序排列，方便同时比较选技能与选模型的优先级。技能显示真实图标与所属英雄，模型显示英雄头像；两类均显示胜率、平均选位、选取率和公式选位。网页的数学引擎直接由桌面程序的 `src/shared/ability-priority.ts` 生成。

## 本地查看

在此目录执行 `npm run dev`，浏览器打开 `http://127.0.0.1:4177`。纯静态页面，无须安装额外依赖。

`npm test` 验证技能与模型映射、原始统计、全部图标与公式计算，检查原有技能的相对顺序不变，并直接测试页面使用的混合排名与筛选函数。发布目录为 `dist/`。

## 数据来源

当前版本使用用户提供的 Windrun `abilities.json`，版本 **7.41f**，源数据更新时间为 **2026-10-15 16:06:11（北京时间）**。共有 513 个技能，标准化总体为 640 行，包含 127 个英雄模型。时间来自文件内的 `_lastUpdated`，页面显示源更新时间，不将导入时间当作数据更新时间。

技能和英雄名称使用 Valve 官方中文数据，513 个技能图标与 127 个英雄头像均打包在本地，页面浏览无需逐个访问外部图床。当前快照的技能名和英雄归属通过 Valve ID 对应，单项技能的判断仍以该快照的游戏版本为准。

从主项目目录执行 `node scripts/prepare-ranking-data.mjs --input "D:\Downloads\abilities.json"` 可从下载文件重新生成数据与图标。导入会严格校验统计值、完整保留原始 JSON，并记录 SHA256；无效文件会直接报错。省略 `--input` 时优先读取 Windrun；接口受限时使用上次导入的 JSON，没有导入文件时才使用原 Excel 参考快照。来源会如实显示。公开原始数据与映射保存在 `source-data/`，不包含用户个人数据库或凭据。

## 公式与交互

全部 640 项共用同一套公式与标准化总体，并统一编号。类型按钮仅筛选总榜：可查看全部、技能、普通技能、终极技能或英雄模型；筛选、搜索和列排序都会保留总榜名次，不会重新从第 1 名编号。当前默认公式下，莉娜模型在总榜第 3，筛选英雄模型后仍显示第 3。模型的公式选位是英雄基础模型的优先级参考，不是该英雄固定技能组合的强度。

页面中的系数和表达式修改只保存在当前浏览器，不会改动桌面程序的设置或原始数据。修改公式会重算全部 640 项及其总榜名次，搜索和英雄筛选不会改变标准化基准。恢复默认后回到原表的胜率系数 -1、选位系数 10。

公式选位允许负数，数值越小越强。它是排序参考值，不是预测胜率，也不是只能取 1–40 的真实选取位置。
